# 무료 사주 작명 도우미

태어난 **년월일시분초**를 입력하면 사주팔자를 계산하고, 부족한 오행을 보완하는 방향으로 아기 이름 후보를 추천하는 무료 윈도우 프로그램입니다.

이 프로그램은 누구나 무료로 내려받아 사용할 수 있습니다. 개인정보를 수집하지 않고, 인터넷 연결 없이도 실행됩니다.

## 다운로드

최신 배포 파일은 아래 GitHub Releases에서 받을 수 있습니다.

[무료 사주 작명 도우미 다운로드](https://github.com/sinmb79/korean-name-maker/releases/tag/v0.1.0)

## 어떤 파일을 받으면 되나요?

- `Setup-x64.exe`: 일반 사용자용 설치 파일입니다. 가장 쉽게 사용할 수 있습니다.
- `Portable-x64.zip`: 설치 없이 압축을 풀고 바로 실행하는 무설치 버전입니다.

처음 사용하는 분은 `Setup-x64.exe`를 권장합니다.

## 사용 방법

1. 다운로드한 `Setup-x64.exe`를 실행해 설치합니다.
2. 프로그램을 엽니다.
3. 성, 성별, 태어난 년월일, 태어난 시분초를 입력합니다.
4. 필요하면 부모 이름, 돌림자, 선호 글자, 제외 글자, 원하는 이름 분위기를 선택합니다.
5. `사주 기반 작명` 버튼을 누릅니다.
6. 추천 이름, 한자, 점수, 사주 보완 내용, 주의할 점을 확인합니다.

## 주요 기능

- 년주, 월주, 일주, 시주 계산
- 일간과 오행 분포 분석
- 부족한 오행을 보완하는 이름 후보 추천
- 부모 이름과 글자 겹침을 보는 가족 조화 참고 점수
- 한자 뜻, 자원오행, 수리사격, 음양 조화 참고
- 발음오행은 낮은 가중치의 참고 항목으로 표시
- 2023~2025년 출생신고 합산 인기 이름 TOP 10 표시
- 추천 결과 복사, 텍스트 저장, 인쇄/PDF 출력
- 오프라인 실행
- 개인정보 미수집

## 이런 분께 좋습니다

- 출생신고 전 아기 이름 후보를 정리하고 싶은 분
- 사주명리 기준으로 부족한 오행을 참고하고 싶은 분
- 너무 흔한 이름인지 최근 통계와 함께 보고 싶은 분
- 작명소 방문 전 여러 후보를 미리 비교하고 싶은 분

## 꼭 읽어주세요

이 프로그램은 작명을 돕는 참고 도구입니다. 이름이 운명을 보장한다고 안내하지 않습니다.

부모 이름은 아기 사주팔자 계산의 필수값이 아닙니다. 입력하면 가족 이름과 같은 이름인지, 글자가 과하게 겹치는지만 참고합니다.

출생신고 전에 한자가 실제로 사용 가능한지는 대법원 인명용 한자 조회로 최종 확인해야 합니다. 현재 버전은 기본 내장 한자 데이터로 동작하며, 공식 전체 인명용 한자 데이터는 계속 보강할 예정입니다.

## 개발자용

개발 환경 실행:

```powershell
npm install
npm run dev
```

```powershell
npm run tauri:dev
```

검사와 빌드:

```powershell
npm run test
npm run lint
npm run build
npm run tauri:build
```
